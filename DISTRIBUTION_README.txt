Harbor v0.3.15 预览版 · Windows x64

1. 完整解压 ZIP，双击 Harbor.exe，只打开管理网页，不显示控制台。保留同目录的 _internal 文件夹。
2. 默认进入账号管理，添加邮箱和密码。
3. 选择新建保留环境或新建无痕环境，启动后自动登录。
4. 登录成功后打开自动任务，选择类型和数量，点击开始。
5. 如未自动识别，先核对网页账号，再点击人工确认登录。

保留环境关闭后可以再次打开；临时环境为了支持插件，采用一次性独立 Chromium 资料目录（不是原生无痕窗口），正常关闭后删除目录和环境列表项，账号和历史保留。异常断电/进程崩溃时可能留下 temporary-plugin-profiles 残留，请在确认浏览器退出后清理。
环境运行时也能编辑账号名称和备注；登录邮箱/密码仍受保护，不重启或打断任务。
删除、关闭、人工确认等操作直接执行，无二次弹窗；删除环境资料不可恢复。
停止任务只停止调度与跟踪，网页中的生成需手动停止。

退出/升级前请保存工作并关闭所有浏览器环境，然后点击网页右上角“退出管理器”。有运行环境或任务时会拒绝退出，不强制中断。关闭网页标签不会关闭后台服务；重新双击 Harbor.exe 会打开已有管理页面。旧版若没有网页退出按钮，仍按旧版原有方式退出，再启动新版。
启动和服务日志保存在 %LOCALAPPDATA%/Harbor/logs；日志可能含本机路径及运行信息，请勿公开。启动失败会尝试打开本地错误提示网页，不要求在控制台按回车。
仅刷新网页或重复启动可能仍打开旧进程。退出时临时环境会被丢弃。
用户资料默认保存在 %LOCALAPPDATA%/Harbor，不随本发行包提供。
不要公开用户数据目录，也不要将管理端口暴露到公网。

本包包含 Python 运行时及 Chromium，无需另行安装。
程序未代码签名；请核实来源并校验 Release 提供的 SHA-256。
自动任务源码已在真实 Arena 完成并发1、间隔15秒的三条短题连续验收，记录和截图保存成功；不代表长动画、Thinking中断或打包 EXE 的完整实站任务验收。干净 Windows 新机验收仍未完成。
官网页面变化可能影响自动化；先小规模检查后使用。
源码与更新：https://github.com/AustinSuun/Harbor

v0.3.10：界面重设计。账号新增搜索与概览；环境支持状态/类型/账号筛选，次要操作收入“更多”。批量操作仅处理当前筛选中选中的环境；任务设置、进度与实验选项分区，小窗口自动适配。

取消最多3个并行的固定上限，可填写任意正整数，实际调度最多为本轮总任务数；本轮总数仍为1–50，发送间隔及停止保护保持。“调度占用”不是实时生成数，“本地结束”不是成功数。v0.3.14 已适配当前 Agent 回复及结束评审面板，修复第一题完成后不继续；多并发保留回归测试覆盖。

v0.3.13：Trace Inspector 3.0.0 和 YesCaptcha 随环境启动自动加载，不再逐个环境设置开关或目录。Trace 随包内置，使用固定扩展ID；首次从旧自定义目录切换不自动迁移旧插件记录和偏好，原资料不删除。不会自动开启 Trace 监听或抽卡，请在插件浮层手动开启。不要同时运行插件抽卡和 Harbor 自动任务。真实模型 trace 恢复尚未确认；任务调度不依赖识别到具体模型。

v0.3.9：GitHub图标、检查更新、当前版本和更新提示移到主内容区右上角。侧栏新增Thinking只读检测：选择已打开的Agent页，采样界面元数据并人工标记阶段，可下载脱敏JSON。不会发送、停止、归档或修改配置；不会保存/导出提示词、推理正文、完整URL、消息ID或Cookie。检测前请自行关闭实验自动停止/归档。当前仍未取得真实Thinking阶段校准结论，不代表旧检测已修复。

本地预览版新增 HTML 结果陈列：全账号合计保留最近 100 个，超出删除最旧结果及对应记录（含收藏/评价）与截图。SVG/CSS 可动态预览，脚本与外网禁用。未取得源文件的任务不进入陈列。首次建立陈列表前自动备份本机数据库。

本版包含工作空间 HTML 自动采集、新成果150行候选标签与网页 GitHub 链接。真实无人值守入柜尚待验收；若文件地址只有手动下载后才出现，自动采集可能失败。候选不是模型身份证明，超过150行不自动淘汰。

YesCaptcha 1.4.7 首次启动时从官方自动下载到本机 plugin-cache，并验证固定 SHA256；无须用户手动安装。首次需要网络，失败会停止本次启动并提示重试，不加载未知文件。官方插件代码不随 ZIP/公开源码再分发。环境页“插件与密钥”只需填写一次 ClientKey，管理器加密保存，所有环境下次启动自动配置；未填/清空时关闭自动解题，填写有效密钥后可能消耗付费点数。保存/清空不影响当前已运行环境，旧密钥直到该环境关闭仍可能在插件中生效。扩展自身本机存储也含敏感配置，请勿共享 profile。

Thinking停止与自动归档已作为实验开关接入，默认关闭。自动归档仅针对已确认停止的Thinking，或已保存且HTML超过150行的鹈鹕结果；本地记录保留。菜单不明确、正在生成或停止未确认时不归档。模拟测试通过，不代表真实Arena页面选择器已校准。限流恢复仍是策略实验，不绕过验证码或限流。

本包为GitHub预览发行版。账号、浏览器资料、文件探测样本和实验输出均不随包提供。

归档/导航异常：已隔离单页导航错误，不再直接取消所有并行任务；浏览器关闭、数据写入失败等仍停止整轮。未复现所有真实归档情况，遇到问题请保留任务记录。

新增更新提醒和Windows一键更新（包括本项目数字版本预览发行）：只从 AustinSuun/Harbor 获取发行包和配套SHA256。先关闭所有环境，再点击一键更新。下载校验后旁路安装、等待旧服务正常退出并启动新版，不覆盖原程序和用户资料。不是发布者数字签名验证；更新失败可继续使用旧程序。首次从旧版升级仍需手动下载本包。

Mac请下载Source code，阅读MACOS.md并运行start-macos.command；此Windows ZIP不能在Mac直接执行。Mac源码启动与钥匙串后端未在真实Mac验收，不提供.app/DMG。

Trace 3.0.0 新增 scripting、unlimitedStorage、notifications 权限；监听完成后的每轮对话本地保存默认开启（尊重已保存的关闭偏好），原始trace存档默认关闭，开启后可能保存令牌和正文。不要共享插件profile或原始导出。Harbor不替用户开启监听或抽卡；限流时停止发送，不自动更换代理或绕过限流。

v0.3.14：发送时临时避开 Trace 浮层，发送后恢复；明确完成信号稳定3秒后释放名额，按设置间隔继续。未知发送结果不重发，线程异常不静默忽略。
