Harbor v0.3.0 预览版 · Windows x64

1. 完整解压 ZIP，双击 Harbor.exe。保留同目录的 _internal 文件夹。
2. 默认进入账号管理，添加邮箱和密码。
3. 选择新建保留环境或新建无痕环境，启动后自动登录。
4. 登录成功后打开自动任务，选择类型和数量，点击开始。
5. 如未自动识别，先核对网页账号，再点击人工确认登录。

保留环境关闭后可以再次打开；临时环境关闭后自动丢弃。
删除、关闭、人工确认等操作直接执行，无二次弹窗；删除环境资料不可恢复。
停止任务只停止调度与跟踪，网页中的生成需手动停止。

升级前请保存工作，在旧管理器控制台 Ctrl+C 并等待退出，再打开新版。
仅刷新网页或重复启动可能仍打开旧进程。退出时临时环境会被丢弃。
用户资料默认保存在 %LOCALAPPDATA%/Harbor，不随本发行包提供。
不要公开用户数据目录，也不要将管理端口暴露到公网。

本包包含 Python 运行时及 Chromium，无需另行安装。
程序未代码签名；请核实来源并校验 Release 提供的 SHA-256。
本版完成构建与静态检查，未完成干净 Windows 机器运行、真实登录及网页任务验收。
官网页面变化可能影响自动化；先小规模检查后使用。
源码与更新：https://github.com/AustinSuun/Harbor
