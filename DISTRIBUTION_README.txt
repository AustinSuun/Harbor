Harbor — Windows x64 内置浏览器版

【开始使用】
1. 将 ZIP 完整解压到一个普通本地文件夹。
2. 双击 Harbor.exe。
3. 程序会自动打开 http://127.0.0.1:8766。
4. 创建环境，启动独立浏览器，在其中手动登录自己的账号。

不需要安装 Python，也不需要安装 Chrome 或单独下载 Playwright Chromium。
管理器会用系统默认浏览器显示管理页；各账号环境由内置 Chromium 打开。
请保留 _internal 文件夹，不要只复制 Harbor.exe。

【退出】
先保存浏览器中的工作，在 Harbor 控制台窗口按 Ctrl+C，并等待退出。
关闭管理页面本身不会停止服务。再次双击程序，如果已有管理器运行，将直接打开页面。
如果端口 8766 已被其他服务占用，程序会提示，不会强制结束其他程序。

【数据】
你的环境、登录资料、任务记录和截图保存在：
%LOCALAPPDATA%\Harbor
程序目录不存放用户数据。发行包不含开发者的账号或登录资料。
升级时可换用新程序文件夹，用户数据仍保留。不要同时运行新旧版本。
删除程序文件夹不会删除用户数据；彻底清除数据前请确认不再需要。

【功能】
独立浏览器环境、鹈鹕任务、纯 HTML+CSS 复刻任务、记录及人工审核。
已移除插件加载、三题数字测试和思考自动归档功能。

【注意】
这是免安装文件夹版，Windows x64；请在受 Chromium 支持的 Windows 桌面系统上使用。
浏览器窗口实际在运行程序的本机显示。网站登录和任务需要联网。
仅供本机使用，不要把管理器端口暴露到公网。
软件尚未代码签名，Windows 可能显示未知发布者提示；请先核实来源。
构建成功不等于通过运行验收。本构建未自动发题、登录或操作网站。
