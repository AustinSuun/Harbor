# Harbor

本地运行的账号、浏览器环境、自动任务与 HTML 结果审核工具。与 Arena.ai 无官方关联。

> **v0.3.10 预览版**：Windows 构建、离线规则和模拟浏览器测试；真实 Arena 页面变化可能导致检测/归档不可用。Thinking 停止、自动归档、YesCaptcha 和 Trace Inspector 均默认关闭。Mac 目前是未经真实 Mac 验收的源码启动支持，不提供原生 .app/DMG。

## Windows 下载与启动

从 [Releases](https://github.com/AustinSuun/Harbor/releases) 下载 `Harbor-Windows-x64-*.zip` 和对应 `.sha256` 校验文件。完整解压，双击 `Harbor.exe`，保留 `_internal` 文件夹。Python 运行时与 Chromium 已包含。

管理地址：`http://127.0.0.1:8766`。不要把管理端口暴露到公网。程序未代码签名；SHA256 用于完整性校验，不等于发布者数字签名。

升级前先保存工作并退出旧管理器。仅刷新网页或重复启动可能仍使用旧进程。临时环境退出会丢弃；账号、备注、历史及保留型配置默认保存在 `%LOCALAPPDATA%/Harbor`，不随安装包分发。

- 浅色主界面与青绿色导航；账号搜索/概览、环境组合筛选、更多操作、全局连接提示、小窗口卡片布局。
- 任务窗口分区，显示计划、已确认发送、回复完成、需查看；保留题目参考、实验设置及安全预览。
- 批量操作仅处理当前筛选中选中的环境，避免影响隐藏项。
- 并行数取消固定3个上限；实际调度不超过本轮总任务数（仍为1–50）。高并行会增加内存与站点负载，发送间隔不变。
- **“调度占用”不是实时生成数，本轮结束不代表全部成功。真实 Arena 的完成检测及并行计数尚未修复或校准。**

## Trace Inspector 插件加载

保留型环境中点击 Trace Inspector，填写完整的本机 Arena Trace Inspector MV3 解压目录；默认关闭，下次启动生效。可与 YesCaptcha 同时加载，不改变临时无痕隔离方式。发行包不包含原插件，也不会自动监听或启动插件抽卡。

插件声明 activeTab/debugger/storage 权限，访问 Arena 与 Trigger.dev。仅校验声明权限与入口文件，不验证签名或全部脚本。原插件自动重命名等已保存偏好不会被重置；不要同时运行插件自动抽卡与 Harbor 自动任务。debugger 附加可能与 DevTools/其他自动化冲突，不强制抢占。仅通过一次性离线 profile 的加载和调试器兼容性测试；真实 trace、模型标签及余额未在本次验收。

首次创建独立插件设置表前备份本机数据库；不上传插件记录、凭据或用户数据。

## 功能

- Windows DPAPI 保护凭据；账号与保留型/临时无痕浏览器环境分离。
- 鹈鹕、快速鹈鹕、火柴人、HTML/CSS 复刻任务；数量、间隔、并发和标签关闭后补位。
- 独立任务页观察工作空间 HTML，不猜文件地址；未取得完整 HTML 不入柜。
- 全账号合计最近100条 HTML 成果；超额删除对应旧记录、评价、收藏及截图。原始 HTML 可下载。
- 新结果显示原始行数、非空行数、150行候选标签；大于150行仍保留本地结果。候选线索不是模型身份证明。
- SVG/SMIL/CSS 隔离预览，禁用 JavaScript 和外网；依赖脚本的动画可能无法预览。
- 保留型环境可配置本机完整解压的 YesCaptcha MV3 插件目录，默认关闭，下次启动生效。不内置第三方插件，不收集 ClientKey；用户在插件内配置密钥和积分。仅结构校验，不验证官方签名。
- 页面导航异常按单条任务隔离，避免因此取消整个并行队列。离开页面不代表服务端停止生成。

## 实验：Thinking 与自动归档

自动任务面板有两个默认关闭的实验选项：

1. 确认当前回复的显式 Thinking 活动标记后，请求停止；不按正文中的词语或图标猜测。只点击一次，不确认停止则不自动归档。
2. 自动归档已确认停止的 Thinking 对话，或完整 HTML 已保存且原始行数大于150的鹈鹕/快速鹈鹕对话。本地成果和审核记录保留。

归档适配器要求当前对话、空闲状态、明确且唯一的当前对话菜单；点击后要同时看到归档提示及离开对话，才标记界面确认。不识别菜单则报告不支持，不盲点、不重试不确定点击。这是待实站校准的保守适配器，不保证当前 Arena 的每种页面布局都可使用。

## Thinking 只读检测（v0.3.9）

侧栏打开检测页，选择本机管理器中已打开的 Agent 标签页。可单次采样，或每秒采样、最长两分钟；人工标记“可见 Thinking / 思考已结束 / 回复完成 / 不确定”，对照现有检测规则。最多保留3组会话、每组120条样本，重启后清空，可下载 JSON 留存。

只观察界面元数据，不发送、停止、归档或修改设置；不保存/导出提示词、推理正文、完整URL、消息ID或Cookie。请先自行关闭实验自动停止和归档。候选标签、动画和停止按钮不等于正在内部推理，也不是模型身份证明。真实 Arena 校准尚未完成；此版本新增诊断工具，不宣称修复 Thinking 识别。

## 更新

GitHub 图标链接、检查更新、当前版本和更新提示位于主内容区右上角，小窗口自动换行。网页提供更新提醒与 Windows 发行版的一键更新，识别本仓库数字版本的预览发行（界面会标记预览版）。检查使用 GitHub API，可能受网络或 API 限额影响，不上传账号数据。

一键更新须先关闭所有环境；不会强制中断任务。只从 `AustinSuun/Harbor` 获取包和同名 SHA256，校验后旁路安装到用户数据目录下的 `updates`，等待旧服务正常退出后启动新版。旧程序和账号数据不覆盖。源码/Mac 不使用 Windows 二进制一键更新。出现问题可手动下载或运行保留的旧包；不承诺所有未来数据库变更都支持降级。

## macOS 源码服务

请阅读 [MACOS.md](MACOS.md)。安装 Python 3.11+，下载源码后运行：

```bash
chmod +x start-macos.command
./start-macos.command
```

脚本建立虚拟环境、安装依赖及 Chromium。数据保存在 `~/Library/Application Support/Harbor`，密码经系统钥匙串存储。Windows 密码不能直接移到 Mac 解密，须重新保存。当前没有真实 Mac 运行验收。
